Button

Triggers an action. Primary is the one main action in a section, secondary supports it, accent is for marketing calls to action, outline and ghost are for lower-emphasis actions.

ClassPurpose
.btn .btn-primaryMain action. Use once per section.
.btn .btn-secondarySupporting action, soft green.
.btn .btn-accentMarketing call to action, brass.
.btn .btn-outline-primaryLower emphasis, outlined.
.btn .btn-ghostLowest emphasis, text only.
.btn .btn-light / .btn-outline-lightFor dark sections such as the hero or footer.
.btn-sm / .btn-lg36 px and 52 px height. Default is 44 px.
.is-loadingShows a spinner and blocks clicks. Add aria-busy="true".
.btn-pillFully rounded corners.

Use <button> for actions (submit, open a menu) and <a> for navigation. Icon-only buttons have their own page: Icon button.
