Container and sections

The page frame: a centered container and vertically spaced sections that every page is built from.

Examples

Container widths

.container (max 1240 px)
.container .container-narrow (820 px, text pages)
.container .container-wide (1440 px, listings with a map)

Change --container-max in 00-tokens.css or layout.css to resize the whole site at once.

Sections

.section-sm
.section .section-surface
.section .section-subtle
.section .section-brand

Alternate plain and tinted sections down the page so each block reads as its own band.

ClassPurpose
