Phase 5 · Global

Animations

Scroll reveals, a hero entrance, stagger and parallax. Everything is switched on with data attributes. Delete the attribute and the effect is gone.

Setup

Add this to the page <head> (it adds the js class that lets content start hidden, and shows everything again if GSAP does not load or the visitor prefers reduced motion):

<script>document.documentElement.classList.add('js');if(window.matchMedia&&matchMedia('(prefers-reduced-motion: reduce)').matches)document.documentElement.classList.add('anim-off');setTimeout(function(){if(!window.__animReady)document.documentElement.classList.add('anim-off')},4000)</script>

Load the scripts at the end of <body>, in this order:

<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/gsap.min.js" defer></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.12.5/dist/ScrollTrigger.min.js" defer></script>
<script src="assets/js/animations.js" defer></script>

Hero entrance

Put data-hero on the hero and data-hero-item on each part, in the order they should appear. An item with data-hero-item="image" always plays last. It plays once on page load (reload this page to see it again).

Delay, duration and repeat

Delay and duration

Delay 0.4s, duration 1.4s

<div data-animate="fade-up" data-animate-delay="0.4" data-animate-duration="1.4"> Defaults: delay 0, duration 0.8 seconds.

Replay every time

Scroll up and down past me

<div data-animate="zoom-in" data-animate-once="false"> By default an effect plays once.

Stagger

Put data-animate-stagger on the parent. Its direct children animate one after another, using the effect set on the parent.

Parallax

Put data-parallax on an element. The number is the speed: higher moves more. Wrap it in a box with overflow: hidden and make it taller than the box so no gap shows. Use it on its own element, not together with data-animate.

<img src="..." data-parallax="0.2">

Attributes

AttributeWherePurpose
data-animateAny elementfade-up, fade-in, fade-down, slide-left, slide-right or zoom-in.
data-animate-delaySame elementSeconds to wait. Default 0.
data-animate-durationSame elementSeconds. Default 0.8.
data-animate-staggerParentSeconds between children. Children animate one by one.
data-animate-onceSame elementfalse to replay on every scroll. Default plays once.
data-parallaxAny elementSpeed factor, for example 0.2.
data-heroHero sectionStarts the entrance timeline on load.
data-hero-itemHero childPart of the timeline, in page order. image plays last.

Only transform and opacity are animated. Animations are skipped for visitors who prefer reduced motion, and content stays visible if JavaScript or GSAP does not load.
