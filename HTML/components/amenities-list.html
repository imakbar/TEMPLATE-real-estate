Phase 3 · Real estate

Amenities list

Features of a property such as pool, parking or air conditioning, as an icon list, a check list or tiles.

Examples

Icon list

  • Swimming pool
  • Garden
  • Parking
  • Gym
  • Air conditioning
  • High-speed internet
  • 24/7 security
  • Pets allowed
  • Elevator
  • Fireplace
  • Laundry room
  • Smart TV

Add class="is-unavailable" to a list item to cross it out.
