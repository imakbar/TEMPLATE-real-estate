Phase 1 · Foundation UI

Rating

Star ratings for agents and reviews, as a display or as a form input.

Examples

Display

4.8 (126 reviews)

Set --rating to any value from 0 to 5, including decimals.

Interactive

Rate this agent

Radios are written from 5 down to 1 and shown 1 to 5. It works with the keyboard and inside forms.

Classes

ClassUse
.rating + --ratingRead-only stars. Sizes .rating-sm (14 px), default (18 px), .rating-lg (24 px).
.rating-summaryStars with a number and review count.
.rating-inputInteractive five-star radio group.
