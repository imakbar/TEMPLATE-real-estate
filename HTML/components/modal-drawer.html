Classes

ClassPurpose
.modalCentered dialog. Sizes .modal-sm, .modal-lg. Needs aria-labelledby on a title.
.modal-confirm + .modal-iconShort confirmation with an icon.
.modal-auth + .divider-textSign in form layout.
.modal-lightboxImage only, on a dark backdrop.
.offcanvas.offcanvas-end + .offcanvas-footerSide drawer with action buttons pinned at the bottom.

All of these use Bootstrap's modal and offcanvas JavaScript, so focus trapping, the Escape key and screen reader support work with no extra code.
