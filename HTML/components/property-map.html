Property map

Properties as price pins on a Google Map. Click a pin to open a card. Pins that are close together group into a cluster.

Example

YOUR_API_KEY is not a real key, so this page shows the demo map. With a real key the same markup shows Google Maps with zoom, drag and clusters.

Setup

  1. Create a key in the Google Cloud Console and turn on Maps JavaScript API. Restrict the key to your website address.
  2. Put the key in data-map-key. If it is empty, or still YOUR_API_KEY, the demo map is shown.
  3. Add your properties as JSON and point data-property-map at it.
<div class="map-view" data-property-map="#map-data" data-map-key="YOUR_API_KEY"></div>

<script type="application/json" id="map-data">
[
  { "id": 1, "lat": 40.730, "lng": -73.987, "price": "$550,000",
    "title": "Maple Court House", "address": "2726 Shinn Street, New York",
    "image": "assets/img/properties/property-1.svg", "url": "property-details.html",
    "status": "sale", "beds": 4, "baths": 3, "area": "2,450 sq ft" }
]
</script>

<script src="assets/js/icons.js"></script>
<script src="assets/js/map-view.js"></script>

If Google rejects the key, the map falls back to the demo map by itself.

Full width

Use .map-view--full for a map that fills the screen below the header, for example on a map listing page.

Attributes and classes

NamePurpose
data-property-mapSelector of the JSON script that holds the properties.
data-map-keyGoogle Maps API key.
data-map-zoomStart zoom. By default the map fits all pins.
data-map-centerlat,lng to start at a fixed place.
.map-viewThe map box (560px high; 480px on phones).
.map-view--fullFull screen height below the header.
.map-pin, .is-rent, .is-activePrice pin. Rent pins are brass. Added by map-view.js.
.map-clusterGroup of close pins. Click to zoom in.
.map-popupProperty card that opens above a pin.

Keyboard: pins are buttons. Escape closes the card, then leaves full screen. Map colors are set in MAP_STYLE at the top of map-view.js.
