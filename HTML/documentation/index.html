Real Estate Template

A clean, modern HTML template for real estate agencies, built on Bootstrap 5 with a Forest Green theme. This guide covers setup, customization and every component.

Introduction

The template is being delivered component by component, then assembled into pages. This release (0.1.0) contains the foundation: design tokens, base styles and the Phase 1 components.

  • Plain HTML, CSS and a little JavaScript. No build step is required to use it.
  • Bootstrap 5.3 compatible. Components extend Bootstrap's own classes, so grid, utilities and JavaScript plugins all keep working.
  • One source of truth for design. Every color, size and radius is a CSS variable, and the names match the variables in the Figma UI Kit.
  • Accessible by default. Visible keyboard focus, readable contrast and reduced-motion support.

Quick start

  1. Unzip the package and open HTML/components/index.html in any modern browser. Nothing needs installing.
  2. Copy the markup of any component from its View code panel into your own page.
  3. Use this head and script setup on every page:
<!-- in <head> -->
<link href="https://fonts.googleapis.com/css2?family=DM+Sans:opsz,wght@9..40,400;9..40,500;9..40,600;9..40,700&family=Fraunces:opsz,wght@9..144,500;9..144,600&display=swap" rel="stylesheet">
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<link href="assets/css/style.min.css" rel="stylesheet">   <!-- always AFTER bootstrap -->

<!-- before </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
<script src="assets/js/icons.js"></script>

style.css is the readable version and style.min.css is the same file minified for production.

Colors

The palette lives in assets/css/src/00-tokens.css in two layers. Primitives are raw values such as --green-900. Semantic tokens such as --color-bg-primary point at primitives and are what components use. To re-brand, change the primitives and every component follows.

TokenValueUsed for
--green-900#173F35Primary buttons, headings, brand surfaces
--green-700#2E6B57Primary hover, links
--green-100#E8EDE7Soft surfaces, secondary buttons
--sand-50#F7F6F0Page background
--charcoal-900#252B28Body text
--brass-500#C0903FAccent buttons, For Rent badge, ratings

Example: to switch the primary color to navy, change the --green-900, --green-700 and --green-950 values and keep the names.

Typography and fonts

Headings (h1 to h4, .display-1, .display-2) use Fraunces. Body text, labels, h5 and h6 use DM Sans. Both are open-source fonts under the SIL Open Font License, which permits commercial use and redistribution.

To change fonts, edit --font-heading and --font-body in 00-tokens.css and update the Google Fonts link in your pages.

Self-hosting fonts (recommended for privacy rules such as GDPR): download the font files, place them in assets/fonts/, remove the Google Fonts link and add @font-face rules to 01-base.css.

Spacing, radius and shadows

Spacing follows a 4 px base: --spacing-2xs (4) to --spacing-4xl (96). Corner radius: --radius-sm 6, --radius-md 10, --radius-lg 16, --radius-xl 24, --radius-full pill. Control heights: --size-control-sm 36, --size-control-md 44, --size-control-lg 52. Shadows: --shadow-sm, --shadow-md, --shadow-lg.

Rebuilding the CSS

Edit the files in assets/css/src/, then compile them into style.css. You need Node.js and nothing else:

cd HTML
node build.js

To create the minified file:

npx esbuild assets/css/style.css --minify --outfile=assets/css/style.min.css

Prefer not to use Node? Edit style.css directly. It is plain, readable CSS. To add a new component file, add it to the ORDER list in build.js.

Bootstrap: CDN or local

Pages load Bootstrap 5.3.8 from the jsDelivr CDN. To work offline or to host everything yourself, download the Bootstrap 5.3 release from getbootstrap.com, copy bootstrap.min.css and bootstrap.bundle.min.js into assets/vendor/bootstrap/, and change the two CDN URLs in each page. The theme only relies on standard Bootstrap 5.3 classes and CSS variables, so any 5.3.x release works.

Icons

Icons are an inline SVG sprite injected by assets/js/icons.js. It works on a web server and when opening files directly from disk. Use an icon like this:

<svg class="icon" aria-hidden="true"><use href="#i-search"></use></svg>

<!-- filled variant for stars and hearts -->
<svg class="icon icon-fill" aria-hidden="true"><use href="#i-star"></use></svg>

Sizes: .icon-sm (16), .icon-md (20), .icon-lg (24). The default is 1.25em so icons scale with text. Color follows the text color.

Included: plus, minus, arrow-right, arrow-left, arrow-up-right, chevron-down, chevron-right, search, close, check, check-circle, info, alert, heart, star, map-pin, bed, bath, area, home, phone, mail, user, sliders, share, upload, trash.

Add your own: open icons.js, add a line to the icons object with a name and the SVG path content (24 x 24 grid, drawn as a 2 px stroke), then use #i-yourname.

Using a component

  1. Open the component page and find the example you want.
  2. Click View code under the example and copy the HTML.
  3. Paste it into your page. Every page needs the Bootstrap CSS, style.css, the Bootstrap JS bundle, and icons.js (for icons). Add site.js for the small behaviors listed below.
  4. Replace the sample text and the images in assets/img/.

To add a page like the ones in components/ for your own component, copy any file there, edit the content inside <main class="doc-main"> and add a line to the list at the top of assets/js/docs-shell.js. The showcase files are not needed on a real site.

JavaScript (site.js)

Small, dependency-free helpers. Each one only runs if its attribute is on the page. Everything else (dropdowns, modals, drawers, tabs, carousel, collapse) is Bootstrap's own JavaScript.

AttributeWhat it does
data-sticky on .site-headerAdds .is-scrolled when the page is scrolled.
.btn-favoriteToggles aria-pressed and the label on click.
data-gallery, data-thumbThumbnail strip that swaps the main photo.
data-gallery-indexOpens the lightbox carousel at a given slide.
data-counter="#id" on a textareaLive character counter.
data-indeterminate on a checkboxShows the mixed state.
data-view-toggle, data-viewGrid and list switch buttons.
data-output="#id" on a rangeShows the slider value in another element.

Accessibility

  • Every interactive element shows a clear 3 px focus ring when reached with the keyboard.
  • Text and control colors are chosen for readable contrast on the page and card backgrounds. Disabled controls are intentionally lower contrast, as the WCAG standard allows.
  • Icon-only buttons must have an aria-label. Decorative icons use aria-hidden="true".
  • Animations (button spinner, skeleton shimmer, smooth scroll) are reduced for users with the "reduce motion" system setting.
  • Remember to run your final pages through a checker such as WAVE or Lighthouse, since content and images are yours.

Browser support

Current versions of Chrome, Edge, Firefox and Safari (desktop and mobile). The theme uses CSS custom properties, :focus-visible and CSS masks, which all of these support. Internet Explorer is not supported, in line with Bootstrap 5.
